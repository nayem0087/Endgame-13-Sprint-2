🛠️ Implemented Functions

1. **Reverse a String (reverseString)** - Reverses the sequence of characters in a string.
2. **Find Maximum (findMax)** - Extracts the highest single numeric value from an array.
3. **Check for Palindrome (isPalindrome)** - Validates if a text string reads identically backward and forward.
4. **Sum Array Elements (sumArray)** - Computes the combined total sum of all values in an array.
5. **Count Vowels (countVowels)** - Counts the total frequency of all vowel characters in a string.
6. **Two Sum (twoSum)** - Locates indices of two numbers that add up to a target sum.
7. **Flatten a Nested Array (flattenArray)** - Unrolls a multi-dimensional array into a single-level array.
8. **Group Anagrams (groupAnagrams)** - Clusters words sharing identical character compositions into sub-arrays.
9. **Longest Substring Without Repeating Characters (lengthOfLongestSubstring)** - Measures the length of the longest contiguous distinct character substring.
10. **Deep Clone an Object (deepClone)** - Duplicates a nested JavaScript object recursively with separate reference memory.
